# Local tstack development

All code and documentation edits belong in a dedicated worktree on its own
branch. Keep the main checkout read-only. Do not commit, push, publish, or
change installed skills unless the current request authorizes it.

This fork supplies delivery workflows. Project instructions own required checks,
review policy, and communication conventions. Global user guidance owns model
routing and account access. Do not copy private account details into this repo.

Validate skill frontmatter, relative links, and the unchanged upstream
full-stop contract before installation. Do not exercise live PR mutations just
to test these instructions; use an isolated fixture or an authorized pilot.
